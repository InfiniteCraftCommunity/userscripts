# Collectable is green | [Install](https://raw.githubusercontent.com/InfiniteCraftCommunity/userscripts/master/userscripts/24sandualexandru/CollectableIsGreen/index.user.js)

This script highlights all collectable items and instances by detecting them through the achievement tracker’s reverse index. Any element identified as collectable is styled with a green theme for quick visual recognition.
